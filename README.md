# jdk1021/tap

Homebrew tap for [AgentDeck](https://github.com/jdk1021/agentdeck) — usage limits, balances and accounts of
AI coding agents in the macOS menu bar (Apple silicon, macOS 14+).

```sh
brew install --cask jdk1021/tap/agentdeck
```

The cask is updated automatically for every AgentDeck release. AgentDeck is ad-hoc signed and not
notarized: on first launch open System Settings > Privacy & Security and choose "Open Anyway".
